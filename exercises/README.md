# Linux exercises

Use these exercises after the relevant lessons. Work in your own home directory or a disposable VM. Try first without looking at solutions.

## Beginner set
1. Print your username and current directory.
2. Create a directory called `linux-lab` with three text files.
3. Copy one file, rename another, and list hidden files.
4. Search a file for a word using `grep`.
5. Explain what `>`, `>>`, and `|` do.
6. Inspect file permissions and set a practice file to owner-only access.

## Intermediate set
7. Find a process you started and inspect it.
8. Search installed packages for a command-line utility.
9. Write a Bash script that checks whether a file exists.
10. Find the IP address and default route of your own machine.
11. Check disk usage and explain the difference between `df` and `du`.
12. Inspect a service and read its logs on a test VM.

## Advanced set
13. Build a system report script with error handling.
14. Create a backup and verify restoration.
15. Diagnose a deliberately stopped service in a VM.
16. Use configuration management to apply a simple repeatable change.
17. Write a troubleshooting report with evidence and a verified fix.

## Solution policy
Solutions should explain the reasoning, not only paste commands. Be careful: commands and outputs differ between distributions. Add your own notes as you solve each problem.
