# Linux knowledge checks

These are self-check questions. Answer in your own words before checking documentation.

## Quiz 1 — Fundamentals
1. What is the kernel?
2. How does a shell differ from a terminal?
3. What does `pwd` display?
4. What is the difference between an absolute and relative path?
5. What does exit status 0 conventionally mean?

## Quiz 2 — Files and permissions
1. What does `ls -la` show?
2. What is the difference between copying and moving a file?
3. What do read, write, and execute mean for a directory?
4. Why is `chmod 777` often unsafe?
5. What is the purpose of `sudo`?

## Quiz 3 — System administration
1. What is a process ID?
2. Why should SIGTERM generally be tried before SIGKILL?
3. What does a package manager do?
4. What is the difference between starting and enabling a service?
5. Where can systemd logs be inspected?

## Quiz 4 — Networking and security
1. What does DNS do?
2. What is a default gateway?
3. Why can ping fail while a website still works?
4. Explain least privilege.
5. Why should security testing be limited to authorized systems?

## Reflection
Which question was difficult? Return to that lesson and explain the answer aloud or in your notes.
