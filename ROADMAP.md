## Suggested milestones
1. Navigate and manipulate files without a graphical file manager.
2. Explain ownership, permissions, and why least privilege matters.
3. Install and update software using your distribution's package manager.
4. Inspect a process and a service; find its logs.
5. Write a Bash script that validates input and handles errors.
6. Diagnose a basic DNS, route, or connectivity issue.
7. Back up data and restore it in a test environment.
8. Document and resolve a simulated system problem.
